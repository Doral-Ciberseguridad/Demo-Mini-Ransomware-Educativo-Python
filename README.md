Pasos para ejecutar y usar esta herramienta:


1. Clona o descarga el repositorio en tu máquina ejecutando este comando:

```
git clone https://github.com/Doral-Ciberseguridad/Demo-Mini-Ransomware-Educativo-Python.git
```


2. Instala las dependencias necesarias (como cryptography) ejecutando en tu terminal:

```
pip install cryptography
```



3. Lanza el script de Python ejecutando en tu terminal:

```
python Mini_Ransomware_Demostracion.py
```
